TALLER 5 - HAMBURGUESAS
Proyecto Java con JUnit 5. Verificado con JDK 17.

ECLIPSE
1. Clone el repositorio o descargue Code > Download ZIP y descomprímalo.
2. File > Import > General > Existing Projects into Workspace.
3. Seleccione la carpeta del repositorio Taller-5-Hamburguesas y termine la importación.
4. Configure un JDK 17 en Java > Installed JREs si Eclipse lo solicita.
5. Seleccione la carpeta tests y use Run As > JUnit Test.
6. En Run Configurations > JUnit > Arguments, el Working directory debe
   ser la raíz del proyecto (la carpeta que contiene data).

CONTENIDO
src: modelo suministrado con correcciones.
tests: prueba original de Ingrediente y las cinco clases exigidas.
data/pruebas: entradas válidas, vacías, repetidas e inválidas.
ESCENARIOS.txt: escenarios, acciones y resultados esperados.
RESULTADOS_JUNIT.txt: salida de ejecución.
cobertura/index.html: informe JaCoCo; abrir con navegador.

CORRECCIONES DESCUBIERTAS
- Combo: aplicar el descuento al precio, no cobrar el valor descontado.
- ProductoAjustado: precio base más adiciones; retiros sin rebaja.
- ProductoAjustado: operaciones públicas para registrar ajustes y texto
  de factura con nombre, costos y saltos de línea.
- Restaurante: crear la carpeta de facturas cuando falte y agregar al
  historial únicamente después de guardar el pedido exitosamente.

Se conserva el modelo del taller. El código usa clases, interfaces,
ArrayList, ciclos, excepciones y java.io; las pruebas usan JUnit 5.
Las pruebas de Restaurante crean facturas en ./facturas y eliminan las
facturas que generan. Los archivos ausentes son escenarios intencionales.
